O **Dodge the Creeps** é um jogo 2D onde o **player** tem como objetivo desviar dos **enemies (inimigos)** que surgem na tela a cada segundo.

A cada **enemy** desviado e autodestruído, o `score` do **player** atualiza no canto superior central da cena.
Ao ser colidido com um **enemy** o **player** morre, resultando em `Game Over!` e sendo exibido o score total do jogo.

# Tecnologias Utilizadas
* **Godot** (Game Engine utilizada)
* **GDScript** (Linguagem utilizada)

# Contexto do Projeto
O **Dodge the Creeps** foi desenvolvido durante as aulas de Desenvolvimento de Jogos, com o objetivo de praticar os tópicos especiais em desenvolvimento de jogos 2D na Godot.
